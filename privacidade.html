Privacidade

Atualizada em 6 de novembro de 2026.

Quem usa

A Sexta-Feira é um app pessoal, usado por uma única pessoa: o próprio dono, que também é quem o mantém. Não há outros usuários.

Onde ficam os dados

Todos os dados ficam no computador do dono, num banco de dados local, com cópias de segurança criptografadas. Nada é guardado em servidores de terceiros pela Sexta-Feira. As autorizações de acesso (como a do Google) ficam criptografadas.

Google Agenda

  • A Sexta-Feira lê os eventos das agendas que o dono escolher, só para mostrá-los a ele junto com as tarefas.
  • Ela cria, muda e apaga na agenda apenas os eventos que correspondem às tarefas que o dono marcou para ir para a agenda.
  • Os dados do Google não são vendidos, compartilhados, usados para publicidade nem enviados a serviços de inteligência artificial.
  • O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
  • O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions; ao desligar a ligação no app, a autorização e a cópia local dos eventos são apagadas.

Outros serviços

Por escolha do dono, a Sexta-Feira pode usar o Open Finance (somente leitura) para trazer o extrato dos bancos dele e uma IA para categorizar gastos e entender anotações rápidas. Os dados do Google Agenda não são enviados a esses serviços.

In short: Sexta-Feira is a single-user personal app. Google Calendar data is only displayed to its owner and used to create events for the tasks he chooses; it is stored locally, never sold, shared or used for advertising or AI, and complies with the Google API Services User Data Policy, including the Limited Use requirements.
